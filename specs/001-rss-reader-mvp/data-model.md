# Data Model: RSS Reader MVP

## FeedSubscription

Represents one URL entered by the user and retained for the lifetime of the API process.

| Field | Type | Rules |
|---|---|---|
| `id` | UUID | Generated by the API when a subscription is accepted; unique within the current process state |
| `url` | URI string | Required absolute URL; scheme must be `http` or `https`; normalized for duplicate comparison |
| `createdAt` | UTC timestamp | Set by the API when the subscription is accepted |

### Relationships

- The subscription list contains zero or more `FeedSubscription` records.
- Each record exists independently; there is no user/account entity in this single-user local MVP.

### Validation and identity

- Trim surrounding whitespace before validation and storage.
- Reject empty input and input that is not an absolute HTTP(S) URL.
- Reject a URL already present after case-insensitive host/scheme comparison and normalization of equivalent URI representation; retain the first accepted entry.
- Do not verify network reachability, response content, RSS/Atom format, or feed title.

### State transitions

```text
Submitted -> Rejected (blank, malformed, unsupported scheme, or duplicate)
Submitted -> Accepted -> Present in in-memory list until API process stops
```

## SubscriptionList

An in-memory collection of `FeedSubscription` records held by a singleton service in the API process. The API is the source of truth for the running session. Restarting the API clears the collection. No remove/update transitions are part of this feature.
